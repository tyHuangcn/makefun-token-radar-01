Launch Radar ranks every pre-token DeFi protocol by implied launch value (model radar-2: TVL × category multiple × growth × patience × chain distribution) and shows how to farm each one — a sortable board, a detail view with the value breakdown and a six-step farm plan, and the already-trading protocols kept apart at the market's own value.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
